# CAI - Código

Repositorio de código del Sistema Integral de Gestión del Centro de Atención Inclusiva (CAI).

## Arquitectura

- Monolito modular con paquetes en `packages/`
- Laravel 11, PHP 8.3
- PostgreSQL
- Fronteras enforced por Deptrac y Arch Tests

## Reglas

Las reglas de gobernanza están en el repositorio de documentación.
